# AI Command Center

Центральный AI-оркестратор для постановки задач, планирования, формирования специализированной команды агентов, памяти и будущего подключения инструментов.

## Что уже есть

- Web-интерфейс, адаптированный под телефон.
- Центральный API на Flask.
- Оркестрация: запрос -> план -> специализированные агенты.
- Автоматическое создание записей агентов под задачу.
- Память решений.
- Журнал событий.
- Интеграционный endpoint Telegram webhook.
- Поддержка Groq через совместимый Chat Completions API.
- Без AI API работает локальный планировщик.
- GitHub Actions проверяет Python и JavaScript синтаксис.

## Переменные Render

- GROQ_API_KEY — необязательно для запуска; нужно для реального AI-планирования и выполнения этапов.
- GROQ_MODEL — по умолчанию openai/gpt-oss-120b.
- TELEGRAM_BOT_TOKEN — добавляется при подключении Telegram.
- TELEGRAM_WEBHOOK_SECRET — секрет webhook.
- GITHUB_TOKEN — зарезервировано для следующего этапа GitHub-инструментов.
- APP_BASE_URL — публичный адрес сервиса.

## Запуск

Build: pip install -r requirements.txt

Start: gunicorn app:app

## Важно

На бесплатном Render локальный файл data/state.json не является постоянным хранилищем. Для production-режима на следующем этапе подключим внешнюю бесплатную/доступную БД или другое постоянное хранилище.

Внешние действия по умолчанию требуют подтверждения. Это сделано специально: сначала проверяем архитектуру и инструменты, затем включаем автономное выполнение.
