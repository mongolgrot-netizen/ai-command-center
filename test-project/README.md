# Тестовый проект

Это минимальное React‑приложение, созданное с помощью **Vite** и **Tailwind CSS**.

## Как запустить
```bash
cd test-project
npm install
npm run dev   # запустит dev‑сервер на http://localhost:5173
```

## Сборка
```bash
npm run build   # создаст статические файлы в ./dist
```

## Деплой
Содержимое папки `dist` можно разместить на GitHub Pages, Netlify, Vercel и т.п.
