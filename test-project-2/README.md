# Тестовый проект 2

A minimal modern single‑page web app that shows a landing page with the title **«Тестовый проект 2»**, a short description and a nice **«Начать»** button.

## Development

```bash
# install dependencies
npm ci

# run the test suite
npm test
```

The CI pipeline (GitHub Actions) runs the same test and will only pass when the page renders correctly.
